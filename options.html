Canvas Agenda

Connection

The address you normally log in at, e.g. https://bcourses.berkeley.edu.

Canvas → Account → Settings → Approved Integrations → + New Access Token. Stored only in this browser profile (chrome.storage.local); it is never sent anywhere but your Canvas server.

Gradescope

Some courses hand work in through Gradescope, which Canvas never hears about. This reads the same pages you do, using the session you are already signed into — there is no password to enter and no API key. Nothing leaves this browser.

Gradescope has no public API, so this depends on the layout of their pages. If they change it, the popup will say it could not read Gradescope rather than quietly showing you an empty list.

Badge

Starred announcements

Canvas has no star feature, so these are kept locally. Starred items always rank as important.

How ranking works

Each announcement is scored on keywords. A match in the title counts full; a match only in the body counts 60%. Pinned adds 30, unread adds 5, starred adds 1000. “Important only” shows anything scoring 75 or above.
